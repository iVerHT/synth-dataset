# Synthetic Dataset Generator

A BlenderProc-based synthetic data generation pipeline
for creating training data for computer vision models.

Similar tools and generators already exist; this project is primarily a personal exploration of synthetic data generation, procedural scene creation, and computer vision.

## Features

- Procedural scene generation
- Randomized object placement
- HDRI-based lighting
- Automatic annotations
- COCO-compatible labels

## Tech Stack

- Python
- BlenderProc
- Blender
- OpenCV
